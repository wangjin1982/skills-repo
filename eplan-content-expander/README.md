## 🎯 使用说明

### 方式一：通过技能扩写

```bash
# 安装技能
cp -r /Users/jackywang/.claude/skills/eplan-content-expander/ ~/Documents/学习笔记/学习笔记/skills/

# 使用技能
echo "请为江苏海航生成业务范围详细内容" | \
  python /Users/jackywang/.claude/skills/eplan-content-expander/scripts/expand_content.py --client 江苏海航 --section business_scope
```

### 方式二：手动添加内容

直接在报告文件 `工作仓库/江苏海航/江苏海航_数字化咨询调研报告.md` 中编辑相应章节，使用扩写模板。

## 📝 扩写模板

### 业务领域扩写模板

**科研开发**（目标：~120 字）：

```
{client_name} 始终将技术创新作为企业发展的核心驱动力。

公司组建了专业的研发团队，专注于高低压电器成套设备的前沿技术研究与产品开发。研发方向涵盖智能化配电技术、电能质量优化、环保型开关设备等多个新兴领域。通过与国内知名高校和科研院所的深度合作，公司不断将最新技术成果转化为实际生产力。
```

**关键信息点**（从用户提供）：
- 研发团队：专业、技术方向
- 专利成果：多项发明和实用新型专利
- 合作院校：国内知名高校和科研院所
- 研发领域：智能化配电、电能质量、环保型开关设备等
- 新兴领域：智能电网、新能源接入、工业自动化控制

## 💡 关键特性

| 特性 | 说明 |
|------|------|
| **目标明确** | 每个章节都有明确的字数目标 |
| **结构化模板** | 所有内容都有预定义的模板结构 |
| **可定制** | 支持根据客户特点调整内容深度和侧重点 |
| **Markdown 格式** | 直接插入到报告中，无需格式转换 |

## 📌 配置说明

扩写内容会根据以下因素进行调整：

- **客户行业特点**：制造型企业 vs 软件业
- **客户规模**：大型、中型、小型
- **业务重点**：技术领先 vs 成本控制 vs 创新能力
- **字数目标**：每章节 500-1000 字
