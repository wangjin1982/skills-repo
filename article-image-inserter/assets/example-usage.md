# 文章配图插入示例

## 示例1：单篇文章插入配图

### 原始文章（节选）

```markdown
# 时间管理法：从"催着做"到"自己管"

"快点写作业!""快点洗澡!"——现代家长似乎永远在追着时间跑。

## 什么是孩子的时间管理?

时间管理≠把时间排满,而是培养三个核心能力。

| 传统方式 | 新方式 |
|---|---|
| "快点做!" | "你打算什么时候完成?" |
| 替孩子安排时间 | 教孩子规划时间 |
| 关注"按时完成" | 关注"如何管理" |
| 家长是计时器 | 孩子是时间主人 |

## 时间管理的三个核心方法

### 方法1:让时间"可见"
...
```

## 示例3：不同文章类型的配图策略

### 类型A：转变型文章

**文章标题**：复盘四步法：从"重复错误"到"螺旋上升"

**配图策略**：
- 图片类型：循环上升的流程图
- 插入位置：对比表格之后
- 图片内容：展示四步循环

**插入位置**：
```markdown
| 传统方式 | 新方式 |
|---|---|
| 重复错误 | 持续改进 |

![[公众号/children-education/review_cycle_visual.png]]

## 复盘四步法详解
```

### 类型B：方法型文章

**文章标题**：GROW模型：从"替孩子想"到"引导孩子想"

**配图策略**：
- 图片类型：四步流程图
- 插入位置：GROW介绍之后
- 图片内容：Goal → Reality → Options → Will

**插入位置**：
```markdown
## 什么是GROW模型?

GROW模型包含四个步骤...

![[公众号/children-education/grow_model_visual.png]]

## GROW模型四步详解
```

### 类型C：概念型文章

**文章标题**：习惯养成策略：从"靠督促"到"自动化"

**配图策略**：
- 图片类型：习惯循环图
- 插入位置：习惯四大定律之后
- 图片内容：提示→渴望→反应→奖励

**插入位置**：
```markdown
## 习惯的四大定律

- 提示定律
- 渴望定律
- 反应定律
- 奖励定律

![[公众号/children-education/habit_loop_visual.png]]

## 如何应用这四大定律
```

## 示例5：检查插入效果

### 插入后的检查清单

```markdown
# 检查清单

## 结构完整性
- [ ] 标题是否保留
- [ ] 章节是否完整
- [ ] 内容是否缺失

## 图片正确性
- [ ] 图片路径正确
- [ ] 图片文件存在
- [ ] 图片清晰可见

## 格式一致性
- [ ] 图片前后有空行
- [ ] 代码块未被破坏
- [ ] 表格格式正确

## 视觉效果
- [ ] 图片位置合理
- [ ] 图片大小适中
- [ ] 图片与内容相关
```
