# 文章配图插入器

## 技能概述

此技能用于为**管理学主题文章**自动插入配图，特别是"从...到..."转变类型的文章。它能智能识别文章结构，在最佳位置插入相关图片，增强视觉效果和阅读体验。

## 使用场景

1. **单篇文章配图**：为一篇已经写好的文章插入配图
2. **批量配图**：为一系列文章批量插入配图
3. **统一格式**：确保所有文章的图片位置一致
4. **智能定位**：自动识别最佳插入位置

## 图片插入原则

### 📍 推荐插入位置

**最佳位置**：对比表格之后

```markdown
| 传统方式 | 新方式 |
|---|---|
| "你必须..." | "你觉得..." |
| 关注结果 | 关注过程 |

![[path/to/image.png]]

## 下一部分标题
```

### 为什么这个位置最好？

1. **视觉强化概念**：读者刚看完文字对比，立即看到视觉化对比
2. **承上启下**：图片展示转变，引出下面的具体方法
3. **打破节奏**：在理论和实践之间提供视觉休息点
4. **公众号友好**：不会太早或太晚，恰到好处

### 其他可选位置

**位置2：文章开头（标题后）**
- 适合：视觉冲击力强的图片
- 优点：第一时间抓住注意力
- 缺点：读者可能还未理解概念

**位置3：实战案例之前**
- 适合：总结性图片
- 优点：理论讲解完成后的视觉总结
- 缺点：距离开头较远

## 使用流程

### 第一步：识别文章结构

读取文章，识别以下关键元素：
- 标题（是否包含"从...到..."）
- 对比表格（传统vs新方式）
- 章节结构
- 现有图片位置

### 第二步：确定图片需求

根据文章内容判断：
- 是否需要配图？
- 什么类型的配图？
- 图片是否已存在？

**管理学文章常见配图类型**：
- 转变流程图（从旧到新）
- 对比图（左右对比）
- 方法示意图（步骤展示）
- 案例场景图

### 第三步：选择插入位置

优先级顺序：
1. **对比表格之后**（首选）
2. 章节标题之后（备选）
3. 文章开头（特殊情况）

### 第四步：插入图片

使用标准Obsidian图片语法：
```markdown
![[path/to/image.png]]
```

或使用相对路径：
```markdown
![[../images/image.png]]
```

### 图片命名规范

- 与文章标题相关
- 使用英文和下划线
- 示例：`time_management_visual.png`

## 批量处理流程

当需要为多篇文档插入图片时：

1. **列出所有文档**
   ```bash
   ls "公众号/孩子的教育/"*.md
   ```

2. **检查每篇文档**
   - 读取文档内容
   - 识别是否已有图片
   - 确定插入位置

3. **批量插入**
   - 按相同规则处理
   - 确保一致性
   - 保留原文内容

## 常见文章类型与配图策略

### 1. 转变型文章（从A到B）

**特征**：标题包含"从...到..."
**配图建议**：左右对比图
**插入位置**：对比表格后

**示例**：
- 时间管理法：从"催着做"到"自己管"
- 反馈技术：从"无效表扬"到"成长反馈"

### 2. 方法型文章（X步法）

**特征**：标题包含"X步法"、"X个方法"
**配图建议**：流程图、步骤图
**插入位置**：方法介绍之后

**示例**：
- 复盘四步法
- GROW模型应用

### 3. 概念型文章（什么是X）

**特征**：标题包含"什么是"
**配图建议**：概念图解、框架图
**插入位置**：概念介绍之后

## 插入时的注意事项

### ✅ 要做的

- 使用相对路径（方便移动）
- 检查图片文件是否存在
- 保留原文的其他内容
- 使用正确的Markdown语法
- 确保图片尺寸合适

### ❌ 不要做的

- 不要破坏原文结构
- 不要重复插入同一图片
- 不要使用绝对路径（除非必要）
- 不要忘记保留空行（图片上下各留一行）

## 快速插入命令

### 为单篇文章插入图片

```markdown
在对比表格后插入：
![[公众号/children-education/time_management_visual.png]]
```

### 批量检查文章

```bash
# 查找所有markdown文件
find "公众号/孩子们的教育" -name "*.md"

# 检查哪些文件包含图片
grep -l "\!\[\[" "公众号/孩子们的教育"/*.md
```

## 常见问题

### Q1: 图片在Obsidian中不显示？

**解决**：
- 检查路径是否正确
- 确认图片文件存在
- 使用相对路径而非绝对路径

### Q2: 图片太大或太小？

**解决**：
- 调整图片原始尺寸
- 或使用HTML语法控制大小
- `![[image.png|300]]`（指定宽度）

### Q3: 多篇文章如何保持图片位置一致？

**解决**：
- 使用相同的插入规则
- 优先选择"对比表格之后"的位置
- 批量处理时保持一致
