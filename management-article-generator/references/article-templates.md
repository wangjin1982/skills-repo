# 文章模板库

此文件提供各类文章部分的详细模板，确保生成的文章结构统一、质量一致。

## 开头引入模板

### 痛点场景引入（用于育儿主题）
```markdown
## 为什么我们总是在[痛点行为]？

"[典型对话1]" "[典型对话2]"——这是[目标读者]最[焦虑/困惑]的时刻。现代家长/管理者似乎陷入了[困境描述]。

企业管理中的[理念名称]告诉我们：[核心理念一句话]。把这个理念应用于[当前主题]，可以让[对象]从[旧状态]，到[新状态]。
```

### 痛点场景引入（用于职场管理）
```markdown
## 为什么[常见问题]总是无解？

"[团队成员/员工的典型抱怨]"——这是管理者最头疼的时刻。传统的[旧方法]似乎越来越失效。

[理念名称]在企业管理中被证明能[核心价值]。同样的理念应用于[具体管理场景]，同样能[预期效果]。
```

### 痛点场景引入（用于自我管理）
```markdown
## 为什么我们总是[不良习惯/问题]？

"[内心独白]"——这是我们都熟悉的自我对话。传统的[旧方法]往往以失败告终。

[理念名称]的核心不是[表面理解]，而是[深层理解]。把这个理念应用于[主题]，可以让我们从[旧状态]，到[新状态]。
```

## 对比表格模板

### 标准对比表格
```markdown
| | |
|---|---|
|[旧方式]家长/管理者|[新方式]家长/管理者|
|"[命令式话术]"|"[引导式话术]"|
|关注[短期结果]|关注[长期成长]|
|替[对象]解决问题|引导[对象]自己解决|
|[旧角色]|[新角色]|
```

### 方法对比表格
```markdown
| | |
|---|---|
|无效[方法]|有效[方法]|
|你真棒！|我注意到你[具体行为]，这带来了[具体影响]|

```

## 实战案例模板

### 对话型案例
```markdown
## 实战案例：[案例标题]

**场景**：[场景描述，包含背景和问题]

**传统[角色]反应**：
[角色]："[传统对话，体现旧方式的问题]"
[对象]："[对象的不良反应]"
[结果描述：问题未解决，甚至恶化]

**新方式对话**：

**[角色]**："[提问1，使用新技巧]"

**[对象]**："[回答1]"

**[角色]**："[提问2，深入引导]"

**[对象]**："[回答2，展现思考]"

**[角色]**："[反馈3，强化正向]"

**[对象]**：([行动描述])"[觉醒时刻]"

**[角色]**："[总结提问，强化学习]"

**[技巧拆解]**：
1. [第一句对话的目的和技巧]
2. [第二句对话的目的和技巧]
3. [为什么这样做有效]
```

## 使用建议

1. **灵活组合**：根据具体主题选择合适的模板
2. **保持一致性**：同一系列文章使用相同的结构
3. **突出特色**：每个理念都要讲透其独特价值
4. **注重实用性**：所有方法和案例都要可操作
5. **语言通俗**：管理学术语要给出通俗解释
