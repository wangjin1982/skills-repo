# 管理学文章生成器

## 技能概述

此技能用于快速生成将**企业管理理念**应用于**特定主题**的系列文章。

支持两种篇幅模式：
- **完整版**：8000-12000字，包含10个完整部分
- **简洁版**：1500-2000字，保留核心内容，精简结构

## 使用流程

### 第一步：理解主题方向

当用户指定主题时，首先明确：
- **目标读者**：通常是35-55岁职场人士
- **应用场景**：如"孩子的教育"、"职场管理"、"自我管理"等
- **核心痛点**：该领域最常见的困惑和挑战
- **篇幅模式**：完整版(8000-12000字) 或 简洁版(1500-2000字)

### 第二步：选择10个管理理念

为该主题选择10个合适的企业管理理念，参考以下分类：

**经典管理框架**：
- 教练式领导力（Coaching Leadership）
- OKR目标管理法
- PDCA循环
- SWOT分析
- GROW教练模型
- 敏捷思维（Agile）

**行为与习惯**：
- 反馈技术（SBI模型）
- 习惯养成策略（原子习惯）
- 时间管理法（四象限、番茄工作法）
- 冲突管理技术

**团队与组织**：
- 项目管理法（WBS、甘特图）
- 团队建设
- 变革管理
- 激励理论（自我决定理论）

**个人发展**：
- 情商培养
- 复盘四步法（AAR）
- 场景化管理

### 第三步：生成每篇文章结构

根据用户选择的篇幅模式，使用不同的文章结构：

#### 完整版结构（10个部分，8000-12000字）

每篇文章必须包含以下10个部分：

#### 1. 标题格式
```
YYYY-MM-DD_管理理念：从"旧模式"到"新模式"
```
例如：`2026-02-01_时间管理法：从"催着做"到"自己管"`

#### 2. 开头痛点场景引入（10-15行）
- 从具体场景切入，引发读者共鸣
- 展示传统方式的困境
- 引出管理理念的必要性

#### 3. 管理理念介绍
- 简要介绍该理念的来源和核心
- 说明如何从企业管理迁移到当前主题
- 强调其价值和适用性

#### 4. 传统方式vs新方式对比表格
```markdown
| | |
|---|---|
|传统家长/管理者|新方式|
|"你必须这样做"|"你觉得可以怎么做？"|
|关注结果|关注过程|
|替他人解决|引导他人解决|
```

#### 5. 具体方法和步骤（核心部分，15-20行）
- 分点列出，每点有小标题
- 提供具体可操作的方法
- 包含话术示例（❌错误 vs ✅正确）
- 必要时使用表格或清单

#### 6. 实战案例（带完整对话，20-30行）
- 展示一个完整的应用场景
- 包含传统方式的错误示范
- 展示新方式的正确对话
- 对话要真实、有层次

#### 7. 常见问题与应对（3个典型问题）
每个问题包含：
- 问题描述
- 原因分析
- 应对策略（分点列出）

#### 8. 工具推荐/模板
- 推荐具体工具或模板
- 说明使用方法
- 必要时提供表格或清单示例

#### 9. 21天练习计划或行动清单
提供分阶段的行动计划：
- 第1周：基础练习
- 第2周：进阶练习
- 第3周：巩固提升
或按"今天/本周/本月"列出行动清单

#### 10. 结语和下期预告
- 用2-3句话升华主题
- 引出下一篇文章的内容

#### 简洁版结构（6个部分，1500-2000字）

适合快速阅读和公众号发布，每篇文章包含以下6个核心部分：

#### 1. 标题格式
```
YYYY-MM-DD_管理理念：从"旧模式"到"新模式"
```
例如：`2026-02-01_时间管理法：从"催着做"到"自己管"`

#### 2. 开头痛点场景引入（5-8行）
- 从具体场景切入，引发共鸣
- 展示传统方式的困境
- 引出管理理念

#### 3. 管理理念简介（3-5行）
- 简要介绍理念核心
- 说明如何应用于当前主题

#### 4. 传统vs新方式对比表格（简化版）
```markdown
| 传统方式 | 新方式 |
|---|---|
| "你必须..." | "你觉得..." |
| 关注结果 | 关注过程 |
```

#### 5. 核心方法（3-5个要点，每个50-80字）
- 提炼最核心的方法
- 每个方法配1个话术示例
- 省略详细说明和案例

#### 6. 简短案例（10-15行）+ 行动清单（3条）
- 一个简短的对话案例
- 3条立即可行的行动建议

**简洁版特点**：
- 省略分年龄段策略
- 省略常见问题详解
- 省略工具推荐详细说明
- 省略21天计划，改为3条行动清单
- 保留核心价值和可操作性

**整体风格**：
- 专业但不晦涩，实用但不浅显
- 使用管理学术语，但给出通俗解释
- 适合35-55岁职场人士阅读
- 强调"管理学+应用场景"的跨界思维

**语言特点**：
- 多用对比表格
- 多用实战对话
- 多用具体案例
- 避免空洞理论
- 每个方法都有可操作的步骤

**标题句式**：
- 统一采用"从'...'到'...'"的句式
- 旧模式：负面、被动、低效
- 新模式：正面、主动、高效

### 第五步：生成文章

使用Task工具批量创建文章，确保：
- 每篇字数在8000-12000字（中文）
- 标题按日期编排（间隔7天）
- 所有文章遵循相同的结构
- 内容连贯，形成系列

## 参考模板

```markdown

"[痛点相关的具体对话/场景]"——这是[目标读者]最[焦虑/困惑]的时刻。

[传统方式的困境描述]

企业管理中的[理念名称]告诉我们：[核心理念]。把这个理念应用于[当前主题]，可以让[读者]从[旧状态]，到[新状态]。
```

```markdown
- 技巧1：[具体说明]

- "[错误话术1]"
- "[错误话术2]"

**✅ 新方式**：
- "[正确话术1]"
- "[正确话术2]"
```

### 实战案例模板
```markdown

**传统方式**：
[角色]："[传统对话]"

**新方式对话**：

**[角色1]**："[对话1]"

**[角色2]**："[对话2]"
```

```markdown

记住：**我们培养的不是[短期目标]，而是[长期愿景]**。

---

**下期预告**：[下一个管理理念]——如何[下一个主题]?
```

## 常见主题适配指南

### 主题：孩子的教育
- 目标读者：家长
- 对象：孩子
- 痛点：作业拖拉、情绪失控、不听话、依赖性强
- 适合理念：教练式领导力、OKR、反馈技术、时间管理等

### 主题：职场管理心得
- 目标读者：管理者、Team Leader
- 对象：团队成员
- 痛点：团队执行力差、员工缺乏动力、沟通成本高
- 适合理念：OKR、PDCA、项目管理、激励理论、团队建设

### 主题：自我管理
- 目标读者：职场人士、创业者
- 对象：自己
- 痛点：拖延、效率低、目标模糊、习惯难养成
- 适合理念：时间管理、习惯养成、GROW模型、复盘法、情商培养

### 主题：夫妻关系管理
- 目标读者：已婚人士
- 对象：伴侣
- 痛点：沟通不畅、冲突频繁、需求不被理解
- 适合理念：冲突管理、反馈技术、教练式沟通、情商培养

## 文件输出规范

- 所有文章保存为Markdown格式
- 文件命名：`YYYY-MM-DD_[理念名称].md`
- 保存路径：根据用户指定（如"公众号/主题名/"）
- 使用中文标点符号
- 表格使用Markdown格式
