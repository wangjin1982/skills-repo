# 书籍笔记自动化创建

## 功能说明

此 skill 用于自动化地为一本管理学书籍创建完整的学习笔记系统，包括：
- **书籍概览**：介绍书籍信息、核心观点、结构框架
- **章节笔记**：为每个章节创建详细笔记，包含主要内容、知识点、分析理解

## 使用场景

当用户说以下内容时触发此 skill：
- "学习这本书：《xxx》"
- "为《xxx》创建笔记"
- "整理《xxx》的笔记"
- "研究《xxx》，帮我把笔记整理好"
- "我想学习《xxx》这本书"

## 输出格式

### 文件命名规范

所有笔记文件名格式：`《书名》-笔记标题.md`

**示例**：
- `《卓有成效的管理者》-书籍概览.md`
- `《高效能人士的七个习惯》-习惯一：积极主动.md`

### 存放位置

**组织方式**：为每本书创建独立的子文件夹

- 子文件夹路径：`管理学经典/书名/`
- 子文件夹名称：使用书名（如：`卓有成效的管理者`、`高效能人士的七个习惯`）

**示例结构**：
```
管理学经典/
├── 卓有成效的管理者/
│   ├── 《卓有成效的管理者》-书籍概览.md
│   ├── 《卓有成效的管理者》第1章-卓有成效是可以学会的.md
│   ├── 《卓有成效的管理者》第2章-掌握自己的时间.md
│   └── ...
└── 高效能人士的七个习惯/
    ├── 《高效能人士的七个习惯》-书籍概览.md
    ├── 《高效能人士的七个习惯》习惯一：积极主动.md
    └── ...
```

## 工作流程

### 步骤1：确认书籍信息

当用户提到一本书时：

**首先确认**：
- 书名是什么？
- 作者是谁？（如果有多个版本，确认要学习的版本）
- 这本书的核心主题是什么？

**搜索策略**：
- 使用 WebSearch 搜索书籍信息
- 搜索关键词：书名 + "summary" / "chapters" / "核心观点"
- 中文书：搜索中文资源（百度百科、知乎、豆瓣等）
- 英文书：搜索英文资源（Amazon、Goodreads、Summary 网站）

---

### 步骤2：创建书籍子文件夹

**创建独立的子文件夹**：

使用 `mkdir` 命令在 `管理学经典/` 下创建以书名命名的子文件夹：

```bash
mkdir -p "管理学经典/书名"
```

**示例**：
- 书名《卓有成效的管理者》→ `管理学经典/卓有成效的管理者/`
- 书名《高效能人士的七个习惯》→ `管理学经典/高效能人士的七个习惯/`

**注意**：
- 子文件夹名称使用纯书名，不包含书名号《》
- 所有后续笔记文件都创建在这个子文件夹中

---

### 步骤3：创建书籍概览笔记

**书籍概览包含以下部分**：

#### 基本信息
- 书名（中英文）
- 作者
- 出版年份
- 标签（如：#书名 #作者 #主题分类）

#### 核心观点
- 书的核心论断
- 作者的革命性洞察
- 与其他书籍的关联

#### 全书结构
- 章节目录
- 内容框架
- 主要部分说明

#### 核心概念
- 书中的重要概念和理论
- 概念的定义和解释
- 对比表格

#### 与其他书的关联
- 与 vault 中其他书籍的对比
- 互补性分析
- 学习建议

**文件名**：`《书名》-书籍概览.md`
**存放位置**：`管理学经典/书名/` 子文件夹中

---

### 步骤4：创建章节笔记

**每个章节笔记包含以下部分**：

#### 章节核心主题
- 柯威的核心论断（引用）
- 章节的要点

#### 章节要点
- 分层次展开的主要内容
- 关键概念解释
- 重要观点和原则

#### 核心概念详解
- 章节中引入的重要概念
- 概念的深入分析
- 实践应用

#### 本章启示
- 从本章得到的核心启发
- 柯威的洞察
- 实践建议

#### 学习要点
- 核心概念表格
- 关键方法/原则
- 实践步骤

#### 实践练习
- 具体的练习方法
- 每日/每周实践
- 行动清单

#### 与其他章节/书籍的关联
- 与本书其他章节的关系
- 与其他书籍的对比
- 延伸阅读

#### 金句摘录
- 作者的经典引用
- 有影响力的语录

**文件名**：`《书名》-章节标题.md`
**存放位置**：`管理学经典/书名/` 子文件夹中

## 内容风格指南

### 写作原则

**1. 结构化**
- 使用清晰的标题层级
- 使用表格组织对比信息
- 使用列表列举要点

**2. 可读性**
- 使用简洁明了的语言
- 避免过度冗长的段落
- 适当使用加粗强调重点

**3. 实用性**
- 包含具体的实践建议
- 提供可操作的练习
- 关联实际应用场景

**4. 深度分析**
- 不仅总结内容，还要提供分析
- 包含自己的理解和洞察
- 与其他书籍进行对比

### 格式规范

**标题层级**：
- `#` 一级标题：笔记标题（书名-章节名）
- `##` 二级标题：主要部分
- `###` 三级标题：子部分
- `####` 四级标题：小节

**表格使用**：
- 用于对比信息
- 用于列举要点
- 用于整理概念

**代码/引用块**：
- 使用 `>` 块引用表示引用原文
- 使用表格表示作者原话

**分割线**：
- 使用 `---` 分隔主要部分
- 使用 `***` 分隔重要提示

## 注意事项

### 质量控制

**准确性**：
- 确保信息来源可靠
- 核对多个来源
- **引用时要标注来源**

**完整性**：
- 不遗漏重要观点
- 保持逻辑连贯
- **覆盖所有章节**

**一致性**：
- 保持风格统一
- 使用相同的格式
- **遵循模板结构**

### 避免的内容

- 不要只是复制粘贴
- 不要过度解读
- **不要编造不存在的内容**

### 来源标注

**在笔记末尾标注来源**：
- WebSearch 的搜索结果链接
- 具体的文章或网站
- **让用户可以追溯信息来源**

## 公众号文章创建（扩展功能）

当用户要求"基于《xxx》创建公众号文章"或"为《xxx》创建公众号文章"时，额外创建公众号风格的文章笔记。

### 工作流程：

1. **文章保存位置**：先保存到 `公众号文章/未发布/` 文件夹
2. **文件命名**：使用简洁的标题，**不要添加【已发布】前缀**
   - ✅ 正确：`为什么努力工作却看不到成果-逻辑思维的力量.md`
   - ❌ 错误：`【已发布】为什么努力工作却看不到成果-逻辑思维的力量.md`
3. **发布流程**：使用 `wechat-draft-publisher` skill 传输到微信公众号草稿箱
4. **发布后处理**：传输成功后，才将文件移动到 `公众号文章/已发布/` 并添加 `【已发布】` 前缀

### 文件命名规范：
- 未发布时：`文章标题.md`（保存在 `未发布/` 文件夹，无前缀）
- 发布后：`【已发布】文章标题.md`（移动到 `已发布/` 文件夹时添加前缀）

### 公众号文章格式：
- 开头故事：用具体人物/场景引入
- 扎心真相：用">"引用金句
- 层次清晰：用"一、二、三..."分段论述
- 表格对比：用表格展示对比信息
- 行动清单：本周可做 + 持续实践
- 写在最后：总结全文，回扣开头故事
- 互动引导：点赞、在看、转发、评论区互动
- 出处说明：注明来源和标签

### 示例参考：

参考已创建的公众号文章作为模板：
- [[公众号文章/未发布/为什么努力工作却看不到成果-逻辑思维的力量]]
