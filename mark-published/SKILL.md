# 标记公众号文章为已发布

## 功能说明

此 skill 用于给"公众号文章"文件夹下的笔记文件名添加【已发布】标记，方便区分已发布和未发布的文章。

## 操作步骤

### 1. 扫描文件夹

使用 Glob 工具扫描公众号文章文件夹：
```
公众号文章/**/*.md
```

### 2. 处理每个文件

对每个文件执行：
1. **检查文件名**：判断是否已包含【已发布】
2. **跳过已标记**：如果已有【已发布】，跳过
3. **添加标记**：如果没有【已发布】，在文件名开头添加

### 3. 使用 Bash 重命名文件

使用 `mv` 命令重命名文件（使用绝对路径）：
```bash
mv "公众号文章/原文件名.md" "公众号文章/【已发布】原文件名.md"
```

### 4. 完成后发送钉钉通知

使用 dingtalk-group-message skill 发送完成通知：
```
公众号文章标记完成：共处理 X 篇文章，其中新增标记 Y 篇，已跳过 Z 篇。
```

## 注意事项

- **只操作"公众号文章"文件夹**，不涉及其他文件夹
- **文件名 vs 内容**：只修改文件名，不修改文档内部内容
- **批量操作**：一次处理所有符合条件的文件
- **跳过已标记**：避免重复添加标记

## 执行脚本

如果需要批量处理，可以使用内置脚本：
```bash
scripts/mark_published.sh
```
