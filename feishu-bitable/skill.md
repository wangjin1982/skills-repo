# 飞书多维表格生成编辑 Skill

## 概述

本Skill提供了将表单数据写入飞书多维表格的完整解决方案，基于实际测试验证的最佳实践，确保数据能够一次性成功导入。

## 核心功能

### 1. 创建多维表格
- 创建独立的飞书多维表格应用
- 自动配置表格名称和权限

### 2. 数据导入
- 支持CSV、Excel、JSON等多种数据源
- 自动创建业务字段
- 批量写入数据记录

### 3. 数据清理
- 删除系统自动生成的空记录
- 删除重复数据记录
- 删除无用模板字段（文本、单选、日期、附件）

### 4. 数据验证
- 验证数据写入完整性
- 提供详细的写入报告

## 重要经验教训

### ❌ 常见问题

1. **创建数据表失败**
   - 问题：在已存在的多维表格中创建新数据表
   - 原因：权限不足（code: 1254001, msg: WrongRequestBody）
   - 解决：创建新的多维表格应用，使用自带的默认数据表

2. **空记录问题**
   - 问题：前面有10行空记录
   - 原因：系统自动生成或多次写入导致
   - 解决：清理所有字段值为None的记录

3. **重复记录问题**
   - 问题：相同数据重复出现
   - 原因：多次写入操作
   - 解决：使用去重算法，只保留唯一记录

4. **模板字段问题**
   - 问题：出现"文本"、"单选"、"日期"、"附件"等无用字段
   - 原因：飞书默认模板
   - 解决：删除这些模板字段，只保留业务字段

### ✅ 最佳实践

1. **每个数据集一个独立应用**
   - 为每个CSV/Excel创建独立的飞书多维表格应用
   - 使用默认数据表，不尝试创建新数据表

2. **先清理后写入**
   - 删除所有现有记录
   - 删除模板字段
   - 创建业务字段
   - 写入业务数据

3. **数据验证**
   - 写入后立即验证记录数
   - 检查第一条记录的内容
   - 确认没有空记录和重复

## 使用场景

- 将CSV数据导入飞书多维表格
- 将Excel数据导入飞书多维表格
- 批量创建数据记录
- 数据清理和去重

## 限制和注意事项

1. 需要有效的飞书应用凭证（APP_ID和APP_SECRET）
2. 租户访问令牌（tenant_access_token）有有效期，需要定期刷新
3. 批量操作限制：每次最多500条记录
4. 字段名不能包含特殊字符

## ⚠️ 已知问题

### 问题1：飞书系统自动生成空记录

**现象：**
- 写入数据后，飞书系统会自动在前面生成10行空记录
- 虽然在写入后执行了清理操作，但空记录仍会出现

**原因分析：**
- 这是飞书系统层面的行为，在创建应用和数据表时自动预分配空记录
- 这些空记录在API响应中存在，但在飞书前端界面可能表现不同
- 可能是飞书的前端缓存或预分配机制导致

**影响：**
- API验证时会看到总记录数 = 业务记录数 + 空记录数（通常多10条）
- 不影响业务数据的完整性和正确性
- 业务记录本身是干净的，只是前面有空记录

**当前处理：**
- Skill已在写入后执行清理操作
- 验证时会统计业务记录数（排除空记录）
- 返回结果中包含 `cleanup` 信息显示清理的空记录数

**建议：**
- 优先使用飞书前端界面查看数据（可能过滤了空记录）
- 如需完全消除空记录，可能需要在飞书前端手动删除
- 这是飞书平台的限制，Skill无法从API层面完全解决

### 问题2：权限限制（需要手动设置）

**现象：**
- 机器人创建的多维表格默认只属于机器人
- 用户打开链接后可能无法直接编辑
- 需要手动设置权限才能编辑

**原因：**
- 使用的是租户令牌（应用级别），创建的资源属于应用
- 自动权限设置API可能需要额外权限或格式调试
- 飞书的权限体系较复杂

**解决方案：**
**方案1：手动设置分享（推荐）**
1. 打开多维表格链接
2. 点击"分享"
3. 设置为"互联网获得链接的任何人"
4. 权限选择"可编辑"

**方案2：禁用自动权限设置**
```python
manager = create_manager(
    app_id="your_app_id",
    app_secret="your_app_secret",
    auto_share=False  # 禁用自动权限设置尝试
)
```

**详细说明：** 见 [PERMISSION_GUIDE.md](PERMISSION_GUIDE.md)

## 输入格式

### CSV文件
```csv
字段1,字段2,字段3
值1,值2,值3
值4,值5,值6
```

### Python字典列表
```python
[
    {"字段1": "值1", "字段2": "值2", "字段3": "值3"},
    {"字段1": "值4", "字段2": "值5", "字段3": "值6"}
```

```
📈 记录数: {count}
```
