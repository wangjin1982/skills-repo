# 飞书多维表格 Skill - 权限设置说明

## ⚠️ 当前限制

### 自动权限设置（部分实现）

**当前状态：**
- Skill已包含权限设置功能代码
- 默认尝试设置为"任何人获得链接可编辑"
- **但由于API限制，可能无法自动设置成功**

**技术原因：**
1. 飞书应用可能需要额外的"云文档"权限
2. 使用的是租户令牌（应用级别），可能需要用户令牌
3. API端点或格式可能需要进一步调试

**影响：**
- 机器人创建的多维表格默认只属于机器人
- 用户打开链接后可能无法直接编辑
- 需要手动设置权限或邀请为协作者

## ✅ 解决方案

### 方案1：手动设置分享权限（推荐）

**步骤：**
1. 在飞书中打开机器人创建的多维表格链接
2. 点击右上角的"分享"按钮
3. 设置为"互联网获得链接的任何人"
4. 权限选择"可编辑"
5. 复制新的分享链接

**优点：**
- 简单直接，100%有效
- 可以精确控制权限范围
- 可以设置过期时间

### 方案2：邀请机器人为协作者（如果需要）

**步骤：**
1. 在飞书中找到机器人创建的多维表格
2. 点击"分享"
3. 在应用列表中找到这个机器人
4. 邀请为"可编辑"或"管理员"

**优点：**
- 机器人可以作为协作者
- 权限关系更明确

### 方案3：创建在用户空间（未来优化）

**计划：**
- 获取用户的个人文件夹ID
- 创建多维表格时指定folder参数
- 这样表格就自动属于用户

**当前限制：**
- 需要额外的API调用获取用户空间
- 可能需要用户级别的授权

## 💡 使用建议

### 对于个人使用
```
1. 使用Skill创建多维表格
2. 点击返回的链接
3. 在飞书中手动设置"分享"权限
4. 设置为"可编辑"
```

### 对于团队使用
```
1. 将多维表格链接分享到团队群聊
2. 团队成员点击链接后请求访问
3. 表格所有者批准访问权限
```

### 对于公开数据
```
1. 设置为"互联网获得链接的任何人可查看"
2. 如需协作，再逐个邀请为可编辑
```

## 🔧 Skill配置

### 禁用自动权限设置

如果权限设置API调用导致错误，可以禁用：

```python
# 创建管理器时禁用自动分享
manager = create_manager(
    app_id="your_app_id",
    app_secret="your_app_secret",
    auto_share=False  # 禁用自动分享
)
```

### 自定义分享类型

```python
# 设置为"可查看"而不是"可编辑"
manager = create_manager(
    app_id="your_app_id",
    app_secret="your_app_secret",
    share_type="anyone_with_link_can_view"  # 可查看
)
```
