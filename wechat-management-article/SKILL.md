# 公众号管理学文章创作

## 概述

基于vault中的管理学笔记（如德鲁克系列），为35-55岁职场人士创作可发表的公众号文章。文章采用故事引入、理论展开、实战建议的结构，自动保存并返回文章链接。

## 目标读者

- **年龄段**：35-55岁
- **职业**：Team Leader、创业者、中高层管理者
- **特征**：有一定职场积累，面临管理压力，渴望提升效能

## 文章结构（五段式）

```
1. 开头故事（小场景引发共鸣）
   └── 用一个具体人物/场景描述痛点

2. 提出问题（扎心真相）
   └── 引出核心矛盾，引用管理大师观点

3. 核心内容（3-5个小节，由浅入深）
   ├── 小节1：概念/特性
   ├── 小节2：方法/步骤
   ├── 小节3：案例/验证
   └── 每节用加粗金句总结

4. 实战建议（行动清单）
   └── 本周可做 + 记录完成后 + 持续实践

5. 结尾激励（行动号召）
   ├── 回归故事人物
   ├── 升华主题
   └── 引导互动（点赞/在看/转发/评论）
```

## 写作规范

### 标题风格

**主标题**：疑问句引发思考
- "你的时间，真的属于你吗？"
- "什么是一个管理者的核心价值？"
- "你是在管理，还是在被管理？"

**副标题**：场景化补充
- "一位管理者找回掌控权的30天"
- "从救火队长到战略领导者的蜕变"
- "德鲁克给出的三个答案"

### 语气风格

- **专业但不生硬**：用"我们"替代"你"，拉近距离
- **有温度有共鸣**：先认同困境，再给出出路
- **避免说教**：用"德鲁克说"代替"你应该"
- **适度加粗**：关键金句用加粗强调，不要过度

### 字数控制

- 开头故事：150-200字
- 问题引入：200-250字
- 核心内容：800-1000字（3-5小节）
- 行动清单：200-250字
- 结尾激励：150-200字
- **总计：1500-2000字**

## 创作流程

```
1. 理解用户需求
   └── 确定主题/参考笔记

2. 搜索相关笔记（可选）
   └── 用Glob/Grep在vault中搜索管理学笔记

3. 读取笔记内容
   └── 提取核心观点、金句、案例

4. 创作文章
   └── 按五段式结构写作

5. 保存文章
   └── 保存到 公众号文章/ 文件夹

6. 返回结果
   └── 显示文章预览 + 文件链接
```

## 自动保存规范

- **文件夹**：`公众号文章/`（自动创建）
- **文件名**：`{主标题}.md`
- **标签**：自动添加 `#管理学 #职场 #公众号` + 主题标签

## 注意事项

1. **确保文件夹存在**：保存前先创建 `公众号文章/` 目录
2. **使用wikilink**：返回时用 `[[公众号文章/xxx]]` 格式
3. **尊重原笔记**：核心观点和金句来自笔记，不编造
4. **保持原创**：故事和展开内容为原创创作
5. **检查字数**：完成后估算字数，确保在1500-2000范围
