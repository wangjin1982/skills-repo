# 模板4：创业避坑指南

## 内容定位
分享创业中的常见错误和避坑经验

## 标题格式示例
- 《我花了10万买的教训：创业千万别做这5件事》
- 《为什么90%的一人公司都倒在了第一阶段？》
- 《创业3年，我最遗憾的3个决定》

## 内容结构（总计约1600字）

### 1. 个人故事引入（300字）
- 讲述一个真实的失败经历（真诚）
- 当时的想法和决策过程
- 造成的后果（具体数字）

**写作要点**：
- 真诚分享，不要美化
- 说明当时为什么会做出错误决策
- 用具体数字说明代价

### 2. 错误分析（400字）
- 问题出在哪（本质分析）
- 为什么当时没意识到（认知盲区）
- 现在如何避免（方法论）

**写作要点**：
- 深入分析错误的根本原因
- 揭示认知盲区
- 提供可操作的避免方法

### 3. 避坑清单（500字）
- **坑1**：描述 + 识别方法 + 避免策略
- **坑2**：描述 + 识别方法 + 避免策略
- **坑3**：描述 + 识别方法 + 避免策略
- 配图：避坑清单可视化

**写作要点**：
- 每个坑都要说清楚如何识别
- 提供具体的避免策略
- 用清单形式便于记忆和执行

### 4. 总结与行动建议（400字）
- 核心教训总结
- 立即可以做的3件事
- 长期需要建立的习惯

**写作要点**：
- 总结可复用的经验
- 给出立即行动指南
- 强调长期习惯的重要性

## 目标读者
AI创业者、一人公司

## 注意事项
- 必须基于真实经历，不要编造
- 保持真诚和谦逊的态度
- 避免说教，而是分享经验
