# 模板7：能力提升路径

## 内容定位
关注一人公司创业者的个人能力提升、职业发展

## 标题格式示例
- 《一人公司需要具备的5项核心能力》
- 《从职场人到创业者：我的能力转型之路》
- 《如何快速掌握一个新领域？我的学习方法论》

## 内容结构（总计约1500字）

### 1. 能力框架（300字）
- 列出核心能力清单（3-5项）
- 每项能力的重要性说明
- 配能力雷达图

**写作要点**：
- 建立清晰的能力框架
- 说明每项能力的价值
- 用图表可视化

### 2. 能力提升方法（每项200字，共600字）
- **能力1**：现状 → 目标 → 提升路径 → 资源推荐
- **能力2**：现状 → 目标 → 提升路径 → 资源推荐
- **能力3**：现状 → 目标 → 提升路径 → 资源推荐

**写作要点**：
- 提供清晰的提升路径
- 推荐具体学习资源
- 设定可达成的目标

### 3. 个人经验（400字）
- 我是如何提升这些能力的
- 踩过的坑和经验总结

**写作要点**：
- 分享真实经历
- 总结可复用的经验
- 坦诚分享失败教训

### 4. 行动清单（200字）
- 未来3个月的提升计划
- 具体的里程碑和检查点

**写作要点**：
- 提供可执行的行动计划
- 设定检查点
- 便于读者复制使用

## 目标读者
AI开发者、创业者、自由职业者

## 注意事项
- 能力框架要完整合理
- 提升路径要可行
- 避免空谈，要有实操价值
