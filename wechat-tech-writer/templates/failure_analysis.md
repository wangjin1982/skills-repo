# 模板10：失败案例分析

## 内容定位
分析失败案例，总结经验教训

## 标题格式示例
- 《为什么他的项目失败了？深度分析3个致命错误》
- 《复盘：这个价值10万的教训，希望你不用经历》
- 《90%的一人公司都死在了这个问题上》

## 内容结构（总计约1400字）

### 1. 案例描述（200字）
- 项目介绍：做什么的
- 投入：时间、金钱、资源
- 结果：失败的具体表现

**写作要点**：
- 客观描述项目情况
- 说明投入和产出
- 明确失败的标志

### 2. 失败原因分析（600字）
- **原因1**：深度分析 + 理论支撑
- **原因2**：深度分析 + 理论支撑
- **原因3**：深度分析 + 理论支撑

**写作要点**：
- 深入分析根本原因
- 避免表面化分析
- 提供理论支撑

### 3. 如何避免（400字）
- **识别信号**：如何提前发现问题
- **预防措施**：具体行动清单
- **补救方案**：如果已经遇到怎么办

**写作要点**：
- 提供预警信号
- 给出预防措施
- 提供补救方案

### 4. 总结与反思（200字）
- 核心教训
- 对读者的建议

**写作要点**：
- 总结可复用的教训
- 给出建设性建议

## 目标读者
AI创业者、一人公司

## 注意事项
- 保持客观，不要指责
- 分析要深入到本质
- 提供建设性的建议
