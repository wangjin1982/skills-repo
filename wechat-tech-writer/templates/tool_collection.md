# 模板11：工具/资源推荐合集

## 内容定位
整合优质工具和资源，为读者提供实用工具箱

## 标题格式示例
- 《一人公司工具箱：我常用的10个提效工具》
- 《创业者必备：这8个资源让你事半功倍》
- 《免费又好用的AI工具清单（持续更新中）》

## 内容结构（总计约1600字）

### 资源清单（每项200字，共1200字）
- **工具1**：名称 + 核心功能 + 适用场景 + 价格 + 优缺点
- **工具2**：名称 + 核心功能 + 适用场景 + 价格 + 优缺点
- **工具3**：名称 + 核心功能 + 适用场景 + 价格 + 优缺点
- ...（列举8-10个）

**写作要点**：
- 每个工具都要说明核心价值
- 明确适用场景
- 诚实说明优缺点
- 提供价格信息

### 使用建议（300字）
- 不同阶段如何选择工具
- 工具组合建议
- 成本控制建议

**写作要点**：
- 提供选择指南
- 建议工具组合方案
- 帮助控制成本

### 我的工具箱（100字）
- 个人正在使用的工具组合
- 月度成本和投入产出比

**写作要点**：
- 分享真实使用情况
- 说明投入产出比

## 目标读者
AI开发者、创业者、一人公司

## 注意事项
- 推荐的工具必须自己用过
- 客观评价，不要只说好话
- 提供多种价位选择
