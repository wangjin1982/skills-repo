# 微信公众号IP白名单配置详细指南

## 问题现状
- 需要添加的IP: **116.211.7.247**
- 错误码: 40164 (IP不在白名单)
- 你的公网IP检测正常，但微信API仍然拒绝访问

## 详细配置步骤（请仔细检查每一步）

### 步骤1: 登录微信公众号平台
访问: https://mp.weixin.qq.com
使用你的管理员账号扫码登录

### 步骤2: 找到正确的配置位置

**正确路径**（请严格按这个路径）:
1. 左侧菜单点击: **设置与开发**
2. 子菜单点击: **基本配置**
3. 在页面中找到: **IP白名单** 部分
   - 位置通常在页面下方
   - 标题是"IP白名单"
   - 旁边有"配置"或"修改"按钮

**注意**:
- ❌ 不是"开发者ID"旁边的IP白名单
- ❌ 不是"公众号设置"里的IP配置
- ✅ 是"基本配置"页面下的"IP白名单"

### 步骤3: 配置IP白名单

1. 点击"配置"或"修改"按钮
2. 在弹出的对话框中输入IP地址:

```
116.211.7.247
```

**格式要求**:
- 每行一个IP
- 或用逗号分隔: 116.211.7.247,8.8.8.8
- 不要加端口号
- 不要加空格
- 不要加http://

**建议同时添加** (两行，每行一个IP):
```
116.211.7.247
172.20.1.251
```

### 步骤4: 保存配置

1. 点击"确定"按钮
2. **重要**: 等待页面显示"保存成功"或类似的提示
3. **重要**: 不要立即关闭页面，等待3-5秒

### 步骤5: 验证配置

1. 刷新当前页面 (F5)
2. 再次查看"IP白名单"部分
3. 确认刚才添加的IP `116.211.7.247` 在列表中显示

### 步骤6: 等待生效

IP白名单配置需要 **1-5分钟** 才能在微信服务器端生效

## 常见问题排查

### Q1: 找不到"IP白名单"在哪里?
A: 请确认:
- 账号类型是否为服务号 (订阅号可能没有此功能)
- 是否有管理员权限
- 是否在"设置与开发 → 基本配置"页面

### Q2: 添加了但还是报错?
A: 请检查:
- 是否点击了保存按钮
- 刷新页面后IP是否还在列表中
- 是否等待了至少1分钟
- IP地址是否完全正确 (116.211.7.247)

### Q3: 是否需要添加多个IP?
A: 建议同时添加:
```
116.211.7.247  (公网IP，必须)
172.20.1.251   (内网IP，建议)
```

### Q4: 账号类型限制?
A: 某些账号类型可能不支持API调用:
- 订阅号: 可能无法使用高级接口
- 未认证的公众号: 功能受限
- 测试号: 有特殊限制
